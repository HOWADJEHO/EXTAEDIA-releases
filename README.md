# EXTAEDIA

Les versions d'EXTAEDIA sont disponibles dans la page
[Releases](https://github.com/HOWADJEHO/EXTAEDIA-releases/releases) :

- l'installeur Windows (`EXTAEDIA_<version>_x64-setup.exe`) et son empreinte SHA-256 ;
- l'application Android (`EXTAEDIA_<version>.apk`).

Une fois installée, l'application propose elle-même les nouvelles versions.
